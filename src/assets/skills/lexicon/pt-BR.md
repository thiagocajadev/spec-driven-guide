# Lexicon: Portuguese (Brazil)

> Instances, not rules. Each `##` heading names a defect class declared in `writing-soul.md`, and each list item is one concrete instance of that class in this language.
> Read `lexicon/en.md` first for the file format. The same parser reads both.

Every entry below is a defect caught in review across several `docs:` cycles, in more than one project. Each one recurs, which is why it earned a line here. Nothing was invented for completeness.

Classes that need judgment do not appear here. An absolute stated without data (`sempre`, `nunca`, `ninguém`), a verbal crutch found by counting repetitions, and a jocose reading of a phrase that is also legitimate (`de quatro` in `campo de quatro dígitos`) all fire on innocent prose, so they live in `checklist-soul.md` Part 2 as a human pass instead.

## Banned adverbs

- realmente
- simplesmente
- basicamente
- literalmente
- fundamentalmente
- profundamente
- verdadeiramente

## Banned openers

- Vamos explorar
- Antes de mais nada,
- Não é exagero dizer

## Banned emphasis

- Vale destacar
- Vale deixar claro
- Vale ressaltar
- É importante notar

## Announcing clause

Names that a reason follows without being the reason. Cut the announcement, open with the information.

- e o motivo é
- o mal-entendido aqui é
- repare que
- a decisão que organiza o resto
- a troca é explícita
- a questão aqui é

## Physical metaphor for mechanics

A physical or spatial verb standing in for what the system does. Replace with the literal verb.

- salta aos olhos → fica visível de imediato
- saltam à vista → ficam visíveis de imediato
- fica presa → fica fixada
- despeja → entrega
- moram → aparecem
- mora → aparece
- convivem → estão no mesmo arquivo que
- convive → está no mesmo arquivo que

## Economic idiom as judgment

Price, cost and payment used to judge a technical decision. Replace with the mechanism.

- se paga
- gasta a palavra
- não dói
- custa caro
- paga o preço
- cobra atraso
- joga fora

## Container metaphor for an abstract set

- uma prateleira de → várias
- uma safra de → várias
- um leque de → várias
- um arsenal de → várias

## Dead idiom

- para por aí → não vai além disso
- e ponto final
- no fim das contas

## Informal register

Slang that lowers the register of a text meant to sound sincere. Name the emotion instead.

- daora → de arrepiar
- bateu comigo → fez sentido pra mim
- bater comigo → fazer sentido pra mim

## Coined jargon

Terms invented while writing, each caught in review. A reader who searches the repository for these finds nothing.

- vizinhos da pergunta
- caminho feliz
- cópia de sessão
- chrome da interface

## Replaced vocabulary

Word the developer swapped, with the word he uses. The dictionary translation is often not the word the reader uses.

- cru → bruto
- arcabouço → plataforma
- primitiva → componente base
- cláusula de guarda → cláusula de proteção
- ramos → o construto real, `if`
